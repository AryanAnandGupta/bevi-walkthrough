1 · How Bevi makes money, as I understand it

Bevi works like a subscription, not a one-time sale

A customer signs up for a machine once, then keeps paying while it is used, refilled and serviced. So the relationship, and the records behind it, last for years.

Why that matters for the systems

Every step of that loop involves a different team, and each keeps its own records. The same customer and site have to stay consistent across all of them for as long as the subscription runs.

Exactly which system each step runs in. That's the first thing I'd want to learn.

What step 2 might show made-up numbers

I've run this loop before

  • Pump-services app. Asked for faster data entry, the real problem was that nobody could tell what state a pump was in.
  • Auto-parts ordering. A recurring stockout was demand hidden by empty shelves, so we counted the shelf instead of guessing it.
  • A statistics project. A "significant" result vanished once placeholder text was cleaned out of the source data.
